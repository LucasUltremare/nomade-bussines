### Run it on your computer / Rode no seu computador

Download `nomade-business-<version>.zip` below, unzip it, and:

| | |
|---|---|
| **Mac** | double-click `Nomade.command`. The first time, right-click → Open → Open. |
| **Windows** | double-click `Nomade.cmd`. If Windows warns, click More info → Run anyway. |
| **Linux** | `./local/nomade.sh` |

No Docker, no admin rights, no install. The first time it downloads Node.js and the database (once), asks four questions and opens the panel. Guides: [Start here](https://github.com/LucasUltremare/nomade-bussines/blob/main/docs/START-HERE.md) · [Comece aqui](https://github.com/LucasUltremare/nomade-bussines/blob/main/docs/COMECE-AQUI.md) · [Empieza aquí](https://github.com/LucasUltremare/nomade-bussines/blob/main/docs/EMPIEZA-AQUI.md).

Baixe o `nomade-business-<versão>.zip` aqui embaixo, descompacte e dê dois cliques no `Nomade.command` (Mac) ou no `Nomade.cmd` (Windows). Sem Docker, sem admin, sem instalar nada. Na primeira vez ele baixa o Node.js e o banco (uma vez só), faz quatro perguntas e abre o painel.

To check the download / Pra conferir o download: `shasum -a 256 -c nomade-business-<version>.zip.sha256`
